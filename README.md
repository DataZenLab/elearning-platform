# Curious-Courses-Elearning
Nền tảng học tập trực tuyến (E-Learning) full-stack được xây dựng bằng NextJS 13 (App Router), TypeScript, Material UI, kết hợp với Strapi Headless CMS và Firebase . Hệ thống hỗ trợ quản lý khóa học bài bản, xác thực người dùng qua JWT và theo dõi tiến độ học tập theo thời gian thực
